# Rust To-Do App

A simple terminal to-do list written in Rust. You can add tasks, view them, and mark them as done from a small menu.

## Features
- Add a task
- View all tasks (done tasks show `[x]`)
- Mark a task as complete
- Quit the app

## How to run
1. Install Rust from https://rustup.rs
2. Clone this repo:
```
   git clone https://github.com/Maveri-Q/rust-todo-app.git
   cd rust-todo-app
```
3. Run it:
```
   cargo run
```

## Example
```
--- To-Do List ---
1. Add task
2. View tasks
3. Complete task
4. Quit
```
